# Техническое задание
Небольшой адаптивный сайт «Список задач» на HTML, CSS и JavaScript без фреймворков, сборки и внешних зависимостей. Добавление кнопкой и Enter, отметка выполнения, удаление, сохранение в localStorage. Пустые и состоящие из пробелов задачи запрещены. Одинаковый текст допустим: действия выполняются по уникальному ID. Вывод текста через textContent. Недоступное хранилище и повреждённые данные не ломают сайт; при неуспешном сохранении показывать предупреждение, повреждённые данные автоматически не перезаписывать. Длинный текст переносится; управление доступно с клавиатуры. Без сервера, БД, регистрации, платных сервисов, AI внутри сайта и дополнительных функций. Не публиковать без разрешения.
