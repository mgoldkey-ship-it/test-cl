# Список задач

Простой список задач для личного использования. Можно:
1. Добавлять задачи кнопкой или клавишей Enter.
2. Отмечать задачи выполненными и возвращать их в невыполненные.
3. Удалять задачи.
4. Сохранять список и статусы после обновления страницы.

**Стек:** HTML, CSS, JavaScript, localStorage. Фреймворков, сборки, сервера приложения, базы данных и внешних зависимостей у сайта нет.

## Локальный запуск

1. Распакуйте архив, сохранив структуру файлов.
2. Откройте файл `index.html` двойным щелчком в Chromium или Chrome. Доступ к интернету для работы сайта не требуется.

Способ с открытием файла `file://` проверен в headless Chromium 158.0.8127.18: добавление и восстановление задачи после обновления прошли. В других браузерах поведение localStorage для `file://` может отличаться; оно не стандартизировано одинаково для всех браузеров.

## Запуск автоматических тестов

Нужны Node.js 20, npm и интернет для установки тестовых инструментов. Из корня распакованного проекта:

```sh
npm install --no-save --no-package-lock playwright@1.65.0
npx playwright install chromium
node tests/browser.cjs
```

Команды проверены в чистой временной копии с отдельной установкой браузера, без зависимости от ранее использованного npm-кэша. На Linux могут понадобиться системные библиотеки для Chromium; при ошибке их отсутствия можно установить их командой `npx playwright install-deps chromium` (потребуются права администратора). Playwright и Chromium нужны **только для тестов**, не для работы сайта. Тесты запускают временный локальный HTTP-сервер на случайном порту исключительно для проверки и записывают скриншоты в `tests/screenshots/`.

Тестовый код: [tests/browser.cjs](tests/browser.cjs); вывод последнего прогона: [tests/results.log](tests/results.log). Скриншоты представлены в `tests/screenshots/`. [Лог проверки чувствительности теста](tests/mutation.log) показывает ожидаемое падение на намеренно изменённой изолированной копии.

## Использование AI

При разработке и тестировании использовался AI-ассистент для подготовки кода и проверок. Внутри сайта AI-функций нет.

## Ограничения

- Данные находятся только в конкретном браузере и для конкретного адреса; синхронизации между устройствами и браузерами нет. Очистка данных браузера может удалить задачи. Адрес `file://` и адрес опубликованного сайта — разные контексты хранения.
- Другие браузеры, реальные мобильные устройства и одновременная работа нескольких вкладок не проверены.
- При сбое записи изменения остаются только в памяти текущей страницы. При повреждённых данных сайт предупреждает пользователя и не перезаписывает их автоматически; восстановление данных в приложении не предусмотрено.
- localStorage не является резервной копией или защищённым хранилищем секретов.
