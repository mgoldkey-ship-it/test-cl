# Контракт
- Ключ localStorage: `todo.tasks.v1`.
- Значение: JSON-массив объектов `{id: string, text: string, completed: boolean}`. ID уникален в пределах списка; текст после trim непустой.
- Операции добавления, изменения отметки и удаления идентифицируют запись по ID. Текст — только через textContent.
- Валидность всех записей и уникальность ID проверяется при загрузке. Повреждённое значение не заменяется автоматически: приложение работает в памяти и предупреждает, что сохранение отключено.
- При недоступном хранилище или ошибке записи приложение работает в памяти и показывает предупреждение. Сообщение об успехе сохранения не показывается.
- Бэкенда, API, БД, LLM и соответствующих контрактов нет.
